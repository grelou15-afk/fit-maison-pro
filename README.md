# FIT MAISON PRO — dépôt GitHub pour HtmlToApk

1. Crée un dépôt GitHub (ex. `fit-maison-pro`) et envoie-y tout le contenu de ce zip (le dossier `.github` doit être à la racine).
2. Dans HtmlToApk : choisis `fit_maison_pro_3_android_native.html`, saisis ce dépôt + ton jeton, puis « Envoyer et fabriquer l'APK ».
3. Récupère l'artefact `mon-application-apk` dans l'onglet Actions.

Test local du script : `python3 tools/apply_spec.py`
