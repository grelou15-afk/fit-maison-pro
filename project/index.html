    5. Fabriquer l’application

    Envoie le projet à ton dépôt GitHub : l’APK est fabriqué en 3 à 6 minutes. Le jeton reste sur cet appareil et ne sert qu’à parler à GitHub.

    Comment créer le jeton

    Sur github.com : photo de profil, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Choisis ton dépôt uniquement, puis dans Permissions : Contents en « Read and write » et Actions en « Read-only ».
